# TenzorPipe v0.2.0

The complete tenzorpipe-v0.2.0.zip includes everything. Alternatively, unzip
 tenzorpipe-v0.2.0-source.zip and tenzorpipe-v0.2.0-binaries.zip into the same
parent directory. Both contribute files to tenzorpipe-v0.2.0/. The source archive
contains the full source, reports, short fixtures and evidence. The binary archive
contains the pinned current Linux binary, three comparison binaries and notices.
After merging, run `sha256sum -c SHA256SUMS` from the repository directory.

Current binary: bin/tenzor-linux-x86_64 (also named bin/tenzor-v0.2.0-linux-x86_64).
Comparators in reference/bin/ are for regression testing, not deployment.
Build and test instructions: BUILD_STATUS.md and scripts/reproduce.sh.
Long media, extra audio media and gen-* video fixtures are regenerated, not bundled.
